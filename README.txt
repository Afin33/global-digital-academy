GLOBAL DIGITAL ACADEMY WEBSITE

Files:
- index.html: website home page
- styles.css: responsive design
- script.js: mobile navigation and year
- ai-content-creators-kit.pdf: downloadable digital product
- brand-banner.png: generated brand banner

PUBLISHING:
1. Extract this ZIP.
2. Upload all files and folders to the root of a GitHub repository.
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the published URL shown by GitHub Pages.

IMPORTANT:
The website is a static starter store. No payment processor, checkout, customer email, or order delivery is connected yet. Before selling, add a supported payment provider and test seller-country eligibility, payout methods, fees, taxes, and digital-delivery rules. Replace any product wording or images you wish to customize.
